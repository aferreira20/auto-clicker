# Auto Clicker

Auto clicker para Windows: botão esquerdo, direito, alternado ou ambos no mesmo ciclo.

## Uso

1. Baixe o `AutoClicker.exe` em **Releases**.
2. Escolha o botão, o intervalo (ms) e, se quiser, clique duplo.
3. Posicione o mouse onde quer clicar e pressione **ESPAÇO** para iniciar o loop.
4. Pressione **ESPAÇO** de novo para parar.

O atalho funciona mesmo com a janela minimizada ou em segundo plano. Marque
"Não repassar a barra de espaço a outros programas" se não quiser que o
espaço chegue ao programa em foco (ex.: um jogo que pula com espaço).

Não precisa instalar nada: usa o .NET Framework 4.x que já vem no Windows 10/11.

## Compilar localmente

Execute `build.bat` no Windows.
